# UnrailedDX11

DirectX 11 と Windows 標準のAPI（XInput / XAudio2）だけで作った、**Unrailed! 風の協力プレイ・ゲーム**です。外部ライブラリは使っていません。
画面上のほぼ全て（地面・木・岩・線路・列車・プレイヤー・文字まで）を **インスタンシング** で描画します（メッシュの種類ごとに 1 ドローコール）。

## ビルド
- **bat**: Visual Studio の「Developer Command Prompt」でこのフォルダに移動し `build.bat` → `build\UnrailedDX11.exe`
- **CMake**: `cmake -B build && cmake --build build --config Release`
- 必要なもの: Visual Studio（C++ デスクトップ開発ワークロード / Windows SDK）のみ。
- `shaders` フォルダは exe の隣（または親フォルダ）に置きます（ビルドスクリプトが自動コピー）。
- 設定は exe と同じ場所の `settings.ini` に保存されます。

## ゲームの流れ
- 走り続ける列車の前に線路を敷き続けます。**線路が途切れて列車が終端に着いたらゲームオーバー**。
- 右端の **ゴール駅の入口** まで線路を繋げば **ステージクリア**。繋がった瞬間から列車が加速して一気にゴールします（**GOAL RUSH!!**）。
- クリアすると **強化ショップ** でボルトを使って強化を買い、次のステージへ進みます（だんだん難しくなります）。

### 物の流れ
**木・岩を採取して持つ → 貨物車両に預ける → レール作成車両が 木+鉄 から線路を作る → 線路を取り出して持つ → 線路の先端に置く**

- **プレイヤーは 1種類の物しか持てません**（木 / 鉄 / 線路のどれか。同じ種類なら最大3個。強化で増やせます）。別の種類を持っている時は拾えないので、先に預けるか、使い切るか、地面に置いてください。
- 持っている物は **頭の上に積んで表示**。画面左上に **プレイヤーごとの持ち物**（`P1 [色] WOOD x2/3` など）が出ます。
- 持っている物は **地面に置けます**（置くボタン）。地面の物は採取ボタンで拾えます。物を渡し合ったり、手がふさがった時の一時置き場に使えます。
- **橋**: **木を持っているプレイヤー** が水に向かって設置ボタンを押すと、持っている木を1本使って橋を架けます。橋の上は歩けて、線路も置けます。

### 貨物車両とレール作成車両
- 列車は **機関車 + 貨物車両（茶）+ レール作成車両（青緑）** の3両です。
- **貨物車両**: 預けられた木（左列）と鉄（右列）を積みます（初期は各20個まで）。
- **レール作成車両**: 貨物車両に 木1 + 鉄1 がある間、約2秒で線路を1本作ります（側面の緑のバーが進み具合）。作った線路は車両の上に積まれます（初期は8本まで）。各ステージの開始時には線路が4本入っています。
- 貨車には、**正面から近づいて向いている時** に触れます（触れる時は貨車の下が黄色く光ります）。

### 列車の当たり判定
列車（機関車・貨車）はすり抜けられません。線路の上に立っていると **押し出されます**（一番短く外へ出られる向きへ。塞がっていれば別の面から外へ）。壁や水・別の車両との間に挟まれて逃げ場が無い時だけリスポーンします（**マルチ**: 他のプレイヤーのランダムな1人の近く / **ソロ**: 列車の近く）。

## ステージの要素
| 要素 | 内容 |
|---|---|
| **駅** | 左端の **スタート駅** と、右端の外側に建つ **ゴール駅**（旗がなびく）。ゴール駅の入口は右端の列の中央3マス（ホーム）。入口以外の右端は柵 |
| **水** | 池。そのままでは歩けず線路も置けません。**木を持っていれば橋を架けられます** |
| **壊れない岩の塊** | 濃い灰色の大きな岩（上に青い結晶）。採取できず通れないので迂回します |
| **木 / 岩** | 採取すると 木 / 鉄 になります |
| **ボルト** | 金色のボルト。近づくと拾えます（チーム共有）。ショップの通貨で、スコアにもなります |

ステージが進むと、列車が速くなり（初速・最高速 +0.05 / ステージ）、池と岩の塊が増えます（上限あり）。

## 強化ショップ（ステージクリア後）
クリア画面で Enter / A を押すと **UPGRADE SHOP** に進みます。ボルトを使って強化を買い、`START NEXT STAGE` で次のステージへ。強化は **ゲームを最初からやり直す（タイトルに戻る）まで続きます**。ボルトはチーム共有で、効果は参加している全員 / 列車に効きます。

| 種類 | 強化 | 効果（1レベルごと） | 最大 | 値段（ボルト） |
|---|---|---|---|---|
| プレイヤー | **MOVE SPEED** | 移動速度 +12% | 5 | 3, 5, 7, 9, 11 |
| | **CARRY CAPACITY** | 持てる量 +1 | 4 | 4, 6, 8, 10 |
| | **HARVEST YIELD** | 採取で獲得個数が +1 になる確率 +15%（持ちきれない分は足元に落ちる） | 5 | 4, 6, 8, 10, 12 |
| | **SMASH CHANCE** | 採取した物の **隣の 木・岩** も一緒に壊れる確率 +12%（壊れた物は地面に落ちる。壊れない岩は対象外） | 5 | 5, 7, 9, 11, 13 |
| 列車 | **CRAFT SPEED** | 線路を作る速さ +25% | 5 | 4, 6, 8, 10, 12 |
| | **TRACK CAPACITY** | レール作成車両の積載量 +2 | 4 | 3, 5, 7, 9 |
| | **CARGO CAPACITY** | 貨物車両の積載量 +10（木・鉄それぞれ） | 4 | 3, 5, 7, 9 |

- スコア = 敷いた線路 × 10 + 拾ったボルト × 50（**使ったボルトも数えます**）+ ステージクリアごとに 500。
- ゲームオーバーからのやり直し（R / Y）は、ステージ開始時の状態（ボルト・貨物・持ち物。買った強化はそのまま）に戻ります。

## 操作
### 1P と参加 / 退出
- **タイトルで「START」を決定した入力が 1P になります**（キーボードで決定 → キーボード1 が 1P、パッドで決定 → そのパッドが 1P）。
- 2P 以降は、ゲーム中に各入力が参加ボタンを押すと参加します（参加した順が 2P, 3P, 4P）。
- **キーボード1も退出できます**（Backspace）。最後の1人は退出できません。誰も居なくなった（パッドの切断など）時は、ゲームが止まって参加を待ちます。

| 入力 | 参加 | 移動 | 採取 / 拾う / 預ける / 取り出す | 設置（線路・橋） | 置く（地面に） | 退出 |
|---|---|---|---|---|---|---|
| キーボード1 | E か Space | WASD（キーボード2が居ない間は矢印も可） | E / Space | Q | F | Backspace |
| キーボード2 | Enter か 右Shift | 矢印キー | Enter | 右Shift | 右Ctrl | Delete |
| パッド (XInput 最大4台) | A か Start | 左スティック / 十字キー | A | X | B | Back（切断でも自動退出） |

- 採取ボタンは、向いている先で動作が変わります: **貨物車両** → 預ける / **レール作成車両** → 線路を取り出す / **地面の物** → 拾う / **木・岩** → 採取。壊れない岩は拾えません（ブザー音）。
- 設置ボタン: **水** → 木を持っていれば橋 / **線路の先端の隣** → 線路を持っていれば置く。
- できない操作（手がふさがっている・材料が無い・木を持っていない など）はブザー音が鳴ります。
- ポーズ: **Esc / P / パッドの Start**（ウィンドウが前面でなくなった時も自動でポーズ）。R で今のステージをやり直し。
- ハイライト: 緑 = 線路を置ける / 水色 = 橋を架けられる / 黄色 = 拾える・預けられる・取り出せる。

メニュー操作: 上下左右 = WASD / 矢印 / パッドの十字キー・左スティック（押しっぱなしで連続入力）、決定 = Enter / Space / A / Start、戻る = Esc / B。

## シーン
```
Title ──START──▶ Playing(ステージ1) ──(列車が終端に到達)──▶ Clear / GameOver
  │  ▲               │  ▲                                        │
  │  │         Esc/Start│                          Clear: Enter / A│
  │  │               ▼  │                                        ▼
  │  │            Paused ──RETRY STAGE / QUIT TO TITLE       Shop (ボルトで強化)
  │  │                                                            │ START NEXT STAGE
  │  └──────── Clear: T / Back,  GameOver: Enter / A              ▼
  │            R / Y = 今のステージをやり直す              Playing(次のステージ)
  └──SETTINGS──▶ Settings ◀──SETTINGS── Paused     (閉じると元の画面へ)
```
- 大きな遷移は **暗転 → シーン切替 → 明転**（暗転中は入力を受け付けません）。ポーズ・設定の出し入れは即座に切り替わります。
- **タイトル**: START / SETTINGS / QUIT。ゲームのマップが背景でスクロールします。
- **ポーズ**: RESUME / RETRY STAGE / SETTINGS / QUIT TO TITLE。
- **ステージクリア**: 結果表示。Enter / A = ショップへ、T / Back = タイトルへ、R / Y = 同じステージをやり直し。
- **ゲームオーバー**: Enter / A = タイトルへ、R / Y = 今のステージをやり直し。
- ゲーム中の大きな表示: **STAGE n**（開始時）/ **GOAL RUSH!!**（線路がゴールまで繋がった時。脈動）/ **DERAILED!**（脱線）/ **GOAL!**（到着）。

### 設定
上下で項目を選び、左右で値を変更。Esc / B で保存して戻ります。

| 項目 | 内容 |
|---|---|
| FULLSCREEN | 枠なしウィンドウで画面いっぱいにします（解像度は変えません）。UI は画面の縦横比に合わせて自動配置 |
| VSYNC | 垂直同期。OFF でティアリングが出る代わりに遅延が減ります |
| SHOW FPS | 画面右上に FPS を表示 |
| MASTER / MUSIC / SFX VOLUME | 全体 / BGM / 効果音 の音量（0〜10）。SFX を変えるたびに確認音が鳴ります |
| RESET TO DEFAULTS | 初期値に戻す |

### サウンド
外部のサウンドファイルは使わず、**XAudio2 だけ**で起動時に効果音とBGMを波形合成して鳴らします（`Audio.cpp`）。オーディオデバイスが無い環境では無音で動きます。

## 構成
```
UnrailedDX11/
├─ build.bat / CMakeLists.txt
├─ shaders/Instancing.hlsl     頂点色 × インスタンス色 + ライティング (lit=0 で UI 用に無効)
└─ src/
   ├─ Config.h        設定値 (マジックナンバーはここに集約。バランス・色・サイズ・UI配置など)
   ├─ Upgrade.h       強化の種類・値段・最大レベル
   ├─ main.cpp        ウィンドウ / メインループ
   ├─ App.h/.cpp      シーン管理 (Title/Settings/Playing/Paused/Clear/Shop/GameOver)・フェード・フルスクリーン
   ├─ Game.h/.cpp     ゲームロジック (ステージ生成・持ち物・貨車・強化・列車の当たり判定) と世界の描画
   ├─ Input.h/.cpp    入力管理 (キーボード2人分 + XInputパッド4台, 参加/退出, メニュー操作)
   ├─ Renderer.h/.cpp インスタンシング描画器 (AddMesh / BeginFrame / Submit / Flush / Present / Resize)
   ├─ Ui.h/.cpp       UI描画 (ドット文字・矩形を立方体インスタンスで描く)
   ├─ Audio.h/.cpp    サウンド (XAudio2。効果音とBGMを合成)
   ├─ Settings.h/.cpp 設定 (settings.ini)
   ├─ Mesh.h / MeshGen.h  頂点・インスタンス・メッシュ生成 (立方体・球・四角錐・六角柱)
   └─ ObjLoader.cpp   OBJローダー (今は未使用。メッシュを差し替えたい時に使う)
```

## インスタンシングの仕組み
1. `Renderer::AddMesh(mesh, 最大数)` … メッシュごとに頂点/インデックスと **DYNAMIC なインスタンスバッファ** を作成（①ロード）
2. 毎フレーム `Submit(メッシュID, ワールド行列, 色)` を呼ぶだけ（地面・木・線路・列車・持ち物・文字まで全部）
3. `Flush(カメラ)` が メッシュごとにバッファへ `Map(WRITE_DISCARD)` で書き込み、`DrawIndexedInstanced` を1回呼ぶ（②描画）
   - 3Dワールド（透視投影・ライティング有り）と UI（正射影・ライティング無し・アルファブレンド）の2回 `Flush` します

> **UI が表示されなくなった場合**: インスタンスバッファの上限（`Config.h` の `kMax*Instances`）を超えると、後から `Submit` した物が描かれません。UI の文字は 1ドット = 1インスタンスなので、HUD だけで約8000個使います（上限は `kMaxCubeInstances = 16384`）。上限を超えた時は、デバッガの出力ウィンドウに警告が出ます。

## 調整・拡張
- 数値の調整は **`src/Config.h`** に集約しています（列車の速度、マップの大きさ、木/岩/池/ボルトの数、持てる数、貨車の容量、強化の効果量、カメラ、色とサイズ、UIの配置 など）。強化の値段・最大レベルは `Upgrade.h` です。
- OBJモデルに差し替える: `LoadObj()` で `MeshData` を読み、`Renderer::AddMesh` で登録 → `Game::Meshes` にIDを追加

## Visual Studio に取り込む場合
`src` 内の全 `.cpp` をプロジェクトに追加し、`shaders\Instancing.hlsl` を exe の隣（または親フォルダ）の `shaders` に置いてください。ソースは UTF-8（BOM付き）です。
